# Security Policy

We take the security and privacy properties of CommandLane seriously.

This repository is for **community resources** only; the main application
codebase is private. However, we still welcome responsible disclosure of
vulnerabilities that may affect CommandLane users.

## Reporting a vulnerability

- Email: **support@commandlane.ai**
- Subject line: `SECURITY REPORT: <short description>`

Please include, where possible:

- A clear description of the issue and impacted component (CLI, desktop app,
  docs site, etc.)
- Steps to reproduce
- Any proof-of-concept code or screenshots
- Your environment (OS, version, etc.)

### Please do **not**

- Publicly post exploit details or proof-of-concept code before we’ve had a
  chance to investigate and respond
- Share other people’s data, credentials, or secrets

## What to expect from us

- We will acknowledge receipt of your report as soon as we see it.
- We will investigate and triage the issue.
- When appropriate, we will:
  - Address the issue in a fix or mitigation
  - Communicate timelines and impact at a high level
  - Credit you (if you wish) in any public notes about the fix

Thank you for helping keep CommandLane and its users safe.
